# Paintlux Studio

![Qt](https://img.shields.io/badge/Qt-6.5+-41CD52?style=for-the-badge)
![Status](https://img.shields.io/badge/status-alpha-orange?style=for-the-badge)
![License](https://img.shields.io/badge/license-GPL--3.0-blue?style=for-the-badge)

Editor de dibujo y pintura digital con capas, máscaras y modo pixel art.
Escrito en C++/Qt 6.

## Inicio rápido

    sudo apt install build-essential cmake qt6-base-dev libqt6svg6-dev
    git clone <
    cd paintlux-studio && mkdir build && cd build
    cmake .. && cmake --build . --parallel
    ./PaintluxStudio

## Funciones core

- **Capas y máscaras**: 12 modos de fusión, máscaras B/N y de color
- **Pinceles**: 15+ presets, pincel personalizado con composición
- **Selección**: rectangular, lazo, varita, vectorial, gizmo
- **Pixel Art**: cuadrícula, animación por frames, exportación GIF
- **Formato .ptx**: guardado por capas con compresión
